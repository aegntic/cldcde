# CLDCDE CI and Deploy

GitHub workflow for pull_request:. Ships repo changes through the CLDCDE automation path.

Install:

```
mkdir -p .github/workflows && \
curl -fsSL "https://raw.githubusercontent.com/aegntic/cldcde/main/.github/workflows/deploy.yml" -o ".github/workflows/deploy.yml" && \
echo "[OK] Installed workflow deploy.yml"
```

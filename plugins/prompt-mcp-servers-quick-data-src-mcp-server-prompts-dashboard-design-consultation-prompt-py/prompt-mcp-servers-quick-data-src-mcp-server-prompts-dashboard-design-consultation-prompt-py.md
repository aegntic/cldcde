# Dashboard Design Consultation Prompt

Dashboard design consultation prompt implementation.

Install:

```
target="${AE_PROMPT_DIR:-$HOME/.claude/prompts}" && \
mkdir -p "$target" && \
curl -fsSL "https://raw.githubusercontent.com/aegntic/cldcde/main/mcp-servers/quick-data/src/mcp_server/prompts/dashboard_design_consultation_prompt.py" -o "$target/dashboard_design_consultation_prompt.py" && \
echo "[OK] Installed prompt dashboard_design_consultation_prompt.py to $target"
```
